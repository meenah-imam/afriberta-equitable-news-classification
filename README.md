# afriberta-equitable-news-classification
This repository contains the manuscript and supporting materials for the study:  “AfriBERTa for Public Good: Toward Equitable News Classification in Low-Resource African Languages.
The work investigates multilingual news topic classification for African languages (Hausa, Yoruba, Swahili) using AfriBERTa and the MasakhaNEWS dataset, with a focus on AI equity and public service deployment.

# Objectives
* Evaluate multilingual news classification in low-resource African languages
* Compare monolingual, multilingual, and cross-lingual learning
* Analyze equity gaps relative to high-resource English systems
* Propose a deployment framework for public sector use

# Methodology
Dataset: MasakhaNEWS
Models:
* TF-IDF + Logistic Regression (baseline)
* AfriBERTa (fine-tuned)

Experimental setups:
* Monolingual
* Multilingual joint
* Cross-lingual transfer
* Evaluation: Weighted F1 Score

# Equity Focus
This study highlights:

* Structural inequalities in NLP resource distribution
* Performance gaps across languages
* Feasibility of inclusive AI for public good

# Key Results
* Yoruba: 93.70% weighted F1
* Hausa: 93.24% weighted F1
* Swahili: 86.16% weighted F1
* Near-English performance achievable with modest data

# Proposed System

A Multilingual Public Information Routing System (MPIRS) for:
* Government dashboards
* Public health communication
* Civic engagement platforms
